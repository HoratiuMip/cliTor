## Brief intro
The *`[C]ommand [L]ine [I]nterpreter [T]ransceiving [O]peration [R]outer `* is a hardware-software standalone package meant to test and stress a wide range of communication protocols and networks. It is build on the BPD arhitecture (bridge-proxy-dock) to allow seamless integration of the selectable modules.

## Junctions
Junctions are the modules that connect to the `bridge` via their `proxys`.
